# vicevault-videos

Cloud pipeline for Vice Vault Clips (GTA 6 shorts, brand ViceVaultClips1).

- `pipeline/PLAYBOOK.md`: the full procedure each scheduled make run follows (08:37 and 17:37 UK time).
- `pipeline/render.py`, `qc.py`, `setup.sh`, `FOOTAGE_INDEX.md`, `specs/`: renderer, voice check, workspace setup, shot index, example specs.
- `music/`: the two channel theme beds.
- `videos/`: finished MP4s. Metricool fetches each one from its raw GitHub link when it is booked.

No secrets go in this repo. Footage is Rockstar's official trailers (picture only, credited).
